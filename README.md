# Control Ward

League of Legends is a popular competitive game, and so there have been several websites made that aim to provide players with analytics and details about their own performance and especially that of other players. For example,
- [OP.GG](https://op.gg/),
- [U.GG](https://u.gg/), and
- [League of Graphs](https://www.leagueofgraphs.com/).

In my experience, these websites are a little cumbersome to use. They have long load times, often require manual refreshes, jam AI features in where they're not needed, and so on. Maybe there's a reason for this, maybe it's bottlenecked by Riot's API, but I would like to at least try to make a version of these websites that runs a little smoother. To that end, I humbly present [controlward.com](https://controlward.com).
